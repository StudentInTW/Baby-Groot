# 資料收集說明（Stage II：每床鏡頭的娃娃影片與照片）

> 2026/11/09 改版：改成具體清單（拍哪幾支影片、每支拍什麼、每段多久，照片每類至少幾張），並加上 11/08 台南那批學到的：
> **鏡頭要近**（嬰兒室的鏡頭是床塞滿畫面）、**手不要入鏡**、直拍也可以。

**這些資料拿來做什麼**：測系統在危險時會不會響、平常會不會亂叫，以及 3 秒警示、照護中、空床這些狀態切換對不對；
也拿來**訓練**判斷「口鼻看不看得到」的小模型（口鼻分類器），和拍 demo。**拿來評估的那一批絕對不能拿去訓練**（見第 6 節）。

**最重要的六件事**

1. **一張床只放一隻娃娃**，手機固定在正上方不動。
2. **拍近一點**：床塞滿畫面，娃娃的頭大約佔畫面寬度的 1/4（第 1 節）。
3. **手不要入鏡**：擺好姿勢、手離開畫面之後，才開始算時間；每個狀態維持 **20–30 秒**。
4. **成對拍**：同一個姿勢先拍口鼻露出來，再只把口鼻擋住，其他都不動（第 3 節）。
5. 每支影片寫下**換姿勢的時間點**（第 5 節）。
6. 每一批（同一天、同一個地點、同一組娃娃）分開放，不要混（第 6 節）。

## 1. 拍攝設定（每一批都一樣）

- **娃娃**：新生兒尺寸（約 45–60 公分），能閉眼就閉眼。一張床一次只放一隻。
- **床**：嬰兒床或床墊都可以；床單、**包巾**、小被子、一個玩偶都要準備。
- **鏡頭**：手機固定在床的正上方（或床頭斜上方），用腳架或固定架，**整支影片不要動**。
  - **要近**：床（或娃娃加周圍一個手掌寬）**塞滿畫面**，娃娃的頭大約佔畫面寬度的 **1/4**。手機離床墊大約 60–80 公分。
    嬰兒室每床的直播鏡頭就是這樣；11/08 那批拍太遠，頭只有畫面寬度的 1/15，嘴有沒有被蓋到就看不清楚。
  - **直拍、橫拍都可以**（嬰兒室的鏡頭多半是直的）。同一支影片不要轉向。
- **手機設定**：不要變焦、不要開濾鏡或人像模式。錄影 1080p、30 fps（4K 檔案太大，用不到）。
  iPhone：設定 → 相機 → 錄影 → 1080p HD、30 fps；設定 → 相機 → 格式 → 選「最相容」。
- **光線**：開燈、昏暗各拍一些（第 3 節的第 7 支）。借得到有紅外線夜視的監視器的話，拍幾段真的夜視畫面——這是目前最缺的資料。
- **手不要入鏡**：手伸進床裡，系統會當成有人在照護（本來就會暫停計時），那一段就測不到警示，手也會擋到臉。
  **頭轉不動的娃娃，不要用手扶著頭**：改成整個身體側躺，背後用捲起來的毛巾撐住（頭跟著身體轉）。

**開始之前**：先拍 1 分鐘（仰睡 → 側睡 → 包巾蓋住整張臉，各 20 秒）傳給 Harry 跑一次，確認系統抓得到這隻娃娃、距離和角度可以，再正式拍。

## 2. 畫面代號

**A. 危險：系統要響**

| | 畫面 | 備註 |
| --- | --- | --- |
| A1 | 趴睡、臉朝下埋進床墊 | |
| A2 | 包巾或被子蓋住整張臉 | |
| A3 | **只蓋住嘴**，眼睛、鼻子露出來 | 目前會漏 ★ |
| A4 | **包巾邊緣滑上來**蓋住口鼻（眼睛露出來） | 目前會漏 ★ |
| A5 | 頭轉開，口鼻被床單或包巾擋住，**只看得到耳朵和後腦** | 目前會把耳朵當成臉 ★ |
| A6 | 口鼻被玩偶、衣物擋住 | |

**B. 安全：系統不要亂叫**

| | 畫面 | 備註 |
| --- | --- | --- |
| B1 | 仰睡、臉朝上 | |
| B2 | **側睡**，口鼻看得到（左、右都要） | 口鼻分類器目前把側睡的側臉當成看不到 ★ |
| B3 | 頭轉開、看得到耳朵，**但口鼻也露在外面** | 跟 A5 成對拍 ★ |

| B6 | 玩偶放在頭旁邊（不碰到臉） | 測會不會把玩偶的臉當成寶寶 |

**C. 狀態切換**

| | 畫面 |
| --- | --- |
| C1 | **照護**：手伸進來調整包巾，再離開 |
| C2 | **正常抱走**：抱起來、床變空，過一陣子再放回來 |
| C3 | 空床放著幾分鐘 |

★ ＝ 目前最缺、最優先。

## 3. 影片：每隻娃娃拍這 8 支（約 30 分鐘）

每個狀態擺好、**手離開畫面之後維持 20–30 秒**再換（換的時候手入鏡沒關係）。箭頭是順序。

| 支 | 拍什麼 | 長度 |
| --- | --- | --- |
| 1 | **側睡朝左**：口鼻露出（B2）→ 包巾邊緣蓋住口鼻（A4）→ 拉開（B2）→ 床單蓋住口鼻（A5）→ 拉開（B2） | 約 2.5 分鐘 |
| 2 | **側睡朝右**：同第 1 支 | 約 2.5 分鐘 |
| 3 | **仰睡、只蓋嘴**：仰睡（B1）→ 只蓋住嘴，眼睛鼻子露出（A3）→ 拉開（B1）→ 包巾蓋住口鼻，眼睛露出（A4）→ 拉開（B1）→ 被子蓋住整張臉（A2）→ 拉開（B1） | 約 3.5 分鐘 |
| 4 | **頭轉開**：頭轉左、口鼻露出（B3）→ 床單擋住口鼻、只看得到耳朵（A5）→ 拉開（B3）→ 換頭轉右，同樣三步。頭轉不動的娃娃：改成側躺、背後墊毛巾，臉稍微朝下 | 約 3 分鐘 |
| 5 | **趴睡**：臉朝下（A1）→ 臉側向左、口鼻露出（B4）→ 臉朝下（A1）→ 臉側向右、口鼻露出（B4）→ 翻回仰睡（B1）。臉側向時用毛巾墊住肩膀，不要用手扶 | 約 2.5 分鐘 |
| 6 | **安全雜項＋狀態切換**：包巾包好（B5）→ 被子蓋到胸口（B5）→ 玩偶放頭旁、不碰臉（B6）→ 手伸進來調整包巾、再離開（C1）→ 抱走，空床 40 秒（C2）→ 放回來，仰睡（B1） | 約 3 分鐘 |
| 7 | **換光線**：第 1、3 支用另一種光線再拍一次（開燈拍的就關燈留小燈，反過來也一樣） | 約 6 分鐘 |
| 8 | **正常睡姿長片**：只擺安全姿勢，每 1–2 分鐘換一次（仰睡、側睡左、側睡右、包巾包好），不蓋口鼻 | 8 分鐘 |

- 時間不夠就先拍 **1、2、3**（★ 的畫面都在這三支）。
- 有好幾隻娃娃時，每隻至少拍 1、2、3；4–8 輪流拍。
- **成對拍**是重點：同一個姿勢先露出口鼻、再只把口鼻擋住，娃娃的位置、頭的角度、鏡頭、光線都不要動。
  如果「看不到」的畫面多半是側頭、「看得到」的多半是正臉，系統會學成「側臉就是看不到」——口鼻分類器試做時就是這樣錯的。

## 4. 照片：每隻娃娃每類至少 5 張（共 30 張）

照片是補充，影片拍完有空再拍。每張稍微換一下位置或角度，**手不要入鏡**，鏡頭一樣要近（同第 1 節）。依畫面放進資料夾，**資料夾名稱就是標註**：

| 資料夾 | 拍什麼 | 每隻娃娃至少 |
| --- | --- | --- |
| `ok_supine` | 仰睡、臉朝上（B1） | 5 張 |
| `ok_side` | 側睡、口鼻看得到（B2，左右各半），或頭轉開、口鼻露出（B3） | 5 張 |
| `warn_prone` | 趴睡但臉側向、口鼻看得到（B4） | 5 張 |
| `alert_facedown` | 臉朝下（A1） | 5 張 |
| `alert_blanket` | 只蓋住嘴（A3）、包巾或被子蓋住口鼻（A2、A4） | 5 張（只蓋嘴至少 2 張） |
| `alert_cover` | 頭轉開、口鼻被擋住（A5），或玩偶、衣物擋住口鼻（A6） | 5 張 |

## 5. 檔案和說明檔（不用畫框）

- **檔名用手機原本的就好**（例如 `IMG_9001.MOV`）。每支影片寫下換姿勢的時間點，可以每支一個同名的說明檔（`IMG_9001.txt`），
  也可以整批寫在一個檔案裡（像 11/08 台南那批）。差 1–2 秒沒關係，用第 2 節的代號：

  ```
  IMG_9001（第 3 支，開燈）
  0:00  仰睡（B1）
  0:25  只蓋住嘴，眼睛鼻子露出（A3）
  0:50  拉開（B1）
  1:15  包巾蓋住口鼻，眼睛露出（A4）
  1:40  拉開（B1）
  ```

  手伸進畫面、手機被碰到也寫一下時間。口鼻看不看得到不用自己判斷，會對照畫面核對。
- 照片的檔名開頭加代號更好（例如 `A3_01.jpg`），沒加也可以，放對資料夾就好。
- 每一批拍完，記下：日期、地點、哪幾隻娃娃、鏡頭位置、開燈還是昏暗。
- **傳檔**：影片、照片和說明檔用雲端硬碟傳**原始檔**給 Harry。不要用 LINE、Messenger 傳，影片會被壓縮。iPhone 的 HEIC 照片直接傳就好，會統一轉檔。

## 6. 評估和訓練要分開

- **一批＝同一天、同一個地點、同一組娃娃拍的**。每一批放一個資料夾，資料夾名稱寫日期和地點（例如 `2026-11-15_台北`）。
- 一批只會有一種用途：**評估**（測系統準不準）或**訓練**（教系統認）。評估的資料一旦拿去訓練，數字就不可信了。
  用途由 Harry 分配，所以**同一批不要拆開，不同批不要混在同一個資料夾**。
- 兩種用途都要，所以至少要拍兩批，而且兩批盡量不一樣：換一天、換一間房或換一張床、換一組娃娃。
- 目前的分法：9–10 月百貨公司那批已經一半訓練、一半評估；11/08 台南那批拿來訓練。**在月子中心用他們的鏡頭拍的，只拿來評估。**

**拍多少**：評估用的要累積到危險、安全片段各 **100 段以上**（目前 41／40 段；多抓或漏抓一段，比例就差 2–3%，看不出改版好壞）。
訓練用的每一批：每隻娃娃 8 支影片＋30 張照片，大約一個下午。

## 7. 隱私與授權

- 入鏡的隊員都要簽官方同意書；非隊員不要入鏡。不要拍到家人照片、門牌、文件。
- **在月子中心拍**：要先取得書面同意；畫面裡不能有真的寶寶、家長或員工；記下鏡頭型號、解析度和安裝高度。拍真的寶寶要等 IRB 通過。
- **真實嬰兒、網路上找到的影片或圖片都不能用**（不能放進作品，也不能拿來訓練）。不要用手機播放嬰兒照片放進床裡拍。
- **AI 生成**只能當補充：用允許商用的工具、保留生成紀錄（工具名稱、提示詞、日期）、跟實拍分開放（`dataset/ai/`）、數字分開算，用在簡報或影片時標示「AI 生成」。很多工具不肯生成「嬰兒臉被蓋住」的畫面，危險情境還是要靠娃娃。
- demo 畫面上的框和燈號一定要是系統真的跑出來的，不能後製。
