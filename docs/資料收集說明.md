# 資料收集說明（Stage II：每床鏡頭的娃娃影片與照片）

> 2026/11/06 改版。舊版是托嬰中心午睡室時期寫的（整間教室、多名幼兒）；現在的題目是月子中心嬰兒室，
> **每床一支固定的俯拍鏡頭、看新生兒**，所以拍法跟著改。同一天晚上補了「成對拍」和側臉（第 3 節）：
> 口鼻分類器試做後發現最缺的就是這些。

**這些資料拿來做什麼**：測系統在危險時會不會響、平常會不會亂叫，以及 3 秒警示、照護中、空床這些狀態切換對不對；
也拿來**訓練**判斷「口鼻看不看得到」的小模型（口鼻分類器），和拍 demo。**拿來評估的那一批絕對不能拿去訓練**（見第 6 節）。

**最重要的五件事**

1. 一支手機只拍一張床，床上只放一隻娃娃；手機固定不動，橫拍、1080p。
2. 影片為主：每個姿勢擺好、手離開畫面之後，維持 15–30 秒再換。
3. **成對拍**：同一個姿勢先拍口鼻露出來，再只把口鼻擋住，其他都不動（第 3 節）。
4. 每支影片附一個同名的說明檔，寫狀態改變的時間點（第 5 節）。
5. 每一批（同一天、同一個地點、同一組娃娃）分開放，不要混（第 6 節）。

## 1. 拍攝設定（每一批都一樣）

- **娃娃**：新生兒尺寸（約 45–50 公分），最好閉眼。至少 2 隻，外觀越不一樣越好（膚色、髮量、大小）。
  **一張床一次只放一隻**，跟嬰兒室一樣。
- **床**：真的嬰兒床，或像嬰兒室那種透明床；床單、**包巾**、小被子都要有。
- **鏡頭**：手機固定在床的正上方或床頭斜上方，**畫面拍整張床、只拍這一張床**（床佔滿大部分畫面、不要拍到隔壁床），
  像嬰兒室每床的直播鏡頭。用腳架或固定架，**整支影片不要動**；要換位置就停下來、開新的一支，並記下來。
- **光線**：開燈、昏暗各拍一份。借得到有紅外線夜視的監視器的話，拍幾段真的夜視畫面——這是目前最缺的資料。
- **手機設定**：橫拍、不要變焦、不要開濾鏡或人像模式。錄影 1080p、30 fps 就好（4K 檔案太大，用不到）。
  iPhone：設定 → 相機 → 錄影 → 1080p HD、30 fps；設定 → 相機 → 格式 → 選「最相容」。

**開始之前**：先拍 1 分鐘的試拍（仰睡 → 臉朝下 → 包巾蓋臉）傳給 Harry 跑一次。系統認不出這個娃娃或這個角度，就先調整，免得白拍。

## 2. 要拍的畫面

**A. 危險：系統要響**

| | 畫面 | 備註 |
| --- | --- | --- |
| A1 | 趴睡、臉朝下埋進床墊 | |
| A2 | 包巾或被子蓋住整張臉 | |
| A3 | **只蓋住嘴**，眼睛、鼻子露出來 | 目前會漏 ★ |
| A4 | **包巾邊緣慢慢滑上來**蓋住口鼻 | 目前臉會一下有一下沒有，打斷 3 秒計時 ★ |
| A5 | 頭轉開，口鼻被床單或包巾擋住，**只看得到耳朵和後腦** | 目前會把耳朵當成臉 ★ |
| A6 | 口鼻被玩偶、衣物擋住 | |

**B. 安全：系統不要亂叫**

| | 畫面 | 備註 |
| --- | --- | --- |
| B1 | 仰睡、臉朝上 | |
| B2 | **側睡或頭轉向一邊**，口鼻看得到 | 口鼻分類器目前把側睡的側臉都當成看不到 ★ |
| B3 | 頭轉開、看得到耳朵，**但口鼻也露在外面** | 跟 A5 成對拍 ★ |
| B4 | **趴睡但臉側向**、口鼻看得到 | 目前判不出來 ★；說明檔要寫「趴睡、臉側向」 |
| B5 | 包巾包好、被子蓋到胸口、手放在臉旁邊（都不擋口鼻） | |
| B6 | 玩偶放在頭旁邊（不碰到臉） | 測會不會把玩偶的臉當成寶寶 |

頭轉向左、轉向右都要有；側睡也是左右兩邊都要。

**C. 狀態切換：測警示流程**

| | 畫面 |
| --- | --- |
| C1 | **照護**：手伸進來換尿布、調整包巾，再離開 |
| C2 | **正常抱走**：寶寶好好的被抱起來、床變空，過一陣子再放回來（目前完全沒有）★ |
| C3 | 空床放著幾分鐘 |

★ ＝ 目前最缺、最優先。

## 3. 怎麼拍：影片為主、照片為輔

系統是看影片、用「口鼻連續 3 秒看不到」判斷的，所以**影片最重要**。

- **一支影片 3–5 分鐘**，依序做 4–6 種狀態。每種狀態擺好、手離開畫面之後，**維持 15–30 秒**再換；換的時候手進畫面沒關係。
  例如：仰睡 → 包巾滑上來蓋住口鼻 → 拉下來 → 頭轉開、口鼻露出 → 床單擋住口鼻、只露耳朵 → 翻回仰睡 → 抱走 → 空床 → 放回來。
- 危險和安全的狀態要交錯，不要一支影片全是危險。
- **另外拍 2–3 段 5–10 分鐘不間斷的正常睡姿**（只擺 B 類，不擺危險姿勢），量系統平常多久會亂叫一次。可以有人走過、伸手摸一下再離開。
- 照片：每種畫面拍幾張，換位置、換角度一點點，放進對應的資料夾（第 5 節）。

**成對拍（很重要）**：同一個姿勢，先拍口鼻露出來的樣子（B 類）15–30 秒，再**只把口鼻擋住**（A 類）15–30 秒，然後拉開。
娃娃的位置、頭的角度、鏡頭、光線都不要動，只改口鼻有沒有被擋。最需要的三組：

| 先拍：口鼻看得到 | 再拍：只把口鼻擋住 |
| --- | --- |
| B1 仰睡 | A3 只蓋住嘴（眼睛、鼻子露出來） |
| B2 側睡、側臉 | A4 包巾邊緣滑上來蓋住口鼻 |
| B3 頭轉開、口鼻露出來 | A5 床單或包巾擋住口鼻，只看得到耳朵和後腦 |

為什麼要這樣拍：如果「看不到」的畫面多半是側頭、「看得到」的多半是正臉，系統會學成「側臉就是看不到」——
口鼻分類器試做時就是這樣錯的（側睡、口鼻看得到的畫面，幾乎全被判成看不到）。成對拍的時候只有口鼻在變，系統才學得到真正的差別。

## 4. 拍多少

| 項目 | 目前 | 目標 |
| --- | --- | --- |
| 危險片段（每段 15–30 秒） | 41 段 | **100 段以上**，★ 的 A3、A4、A5 每種至少 15 段 |
| 安全片段 | 40 段（多半只有 2–6 秒） | **100 段以上**，★ 的 B2、B3 每種至少 15 段（跟 A 類成對拍），再加 2–3 段 5–10 分鐘的正常睡姿 |
| 照護、正常抱走、空床 | 2 支片段 | 每種 **10 次以上** |
| 照片 | 114 張、185 隻 | 每種畫面 **20 張以上**，共約 300 張 |

為什麼要 100 段左右：目前 41 段裡多抓或漏抓一段，比例就差 2–3%，跟改版前後的差距一樣大，看不出好壞。

粗估：一支影片 3–5 分鐘，拍 25–30 支，大約 2–3 個下午（一批）。

## 5. 檔案和說明檔（不用畫框）

- **檔名用手機原本的就好**（例如 `IMG_9001.MOV`）。**每支影片附一個同名的說明檔**（`IMG_9001.txt`），
  只寫狀態改變的時間點，差 1–2 秒沒關係，用第 2 節的代號：

  ```
  0:00  仰睡（B1）
  0:20  包巾慢慢拉上來，0:24 蓋住口鼻（A4）
  0:50  拉下來（B5）
  1:10  頭轉開，口鼻露出來（B3）
  1:35  床單擋住口鼻，只看得到耳朵（A5）
  2:00  抱起來，床變空（C2）
  2:50  放回來，仰睡（B1）
  ```

  手伸進畫面、手機被碰到也寫一下時間。口鼻看不看得到不用自己判斷，會對照畫面核對。
- 照片依畫面分資料夾，**資料夾名稱就是標註**：`ok_supine`（B1）、`ok_side`（B2、B3、B5、B6）、`warn_prone`（B4）、
  `alert_facedown`（A1）、`alert_blanket`（A2、A3、A4）、`alert_cover`（A5、A6）。檔名開頭加代號，例如 `A3_01.jpg`。
- 每一批拍完，記下：日期、地點、哪幾隻娃娃、鏡頭位置、開燈還是昏暗。
- **傳檔**：影片、照片和說明檔用雲端硬碟傳**原始檔**給 Harry。不要用 LINE、Messenger 傳，影片會被壓縮。

## 6. 評估和訓練要分開

- **一批＝同一天、同一個地點、同一組娃娃拍的**。每一批放一個資料夾，資料夾名稱寫日期和地點（例如 `2026-11-15_實驗室`）。
- 一批只會有一種用途：**評估**（測系統準不準）或**訓練**（教系統認）。評估的資料一旦拿去訓練，數字就不可信了。
  用途由 Harry 分配，所以**同一批不要拆開，不同批不要混在同一個資料夾**。
- 兩種用途都要，所以至少要拍兩批，而且兩批盡量不一樣：換一天、換一間房或換一張床、換一組娃娃。
- 已經有的資料（9–10 月拍的影片和照片）已經分好一半訓練、一半評估。下一批的重點是 ★ 的畫面，特別是第 3 節的成對拍。

## 7. 隱私與授權

- 入鏡的隊員都要簽官方同意書；非隊員不要入鏡。不要拍到家人照片、門牌、文件。
- **真實嬰兒、網路上找到的影片或圖片都不能用**（不能放進作品，也不能拿來訓練）。
- **AI 生成**只能當補充：用允許商用的工具、保留生成紀錄（工具名稱、提示詞、日期）、跟實拍分開放（`dataset/ai/`）、數字分開算，用在簡報或影片時標示「AI 生成」。很多工具不肯生成「嬰兒臉被蓋住」的畫面，危險情境還是要靠娃娃。
- demo 畫面上的框和燈號一定要是系統真的跑出來的，不能後製。
