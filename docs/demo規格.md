# Demo 規格：偵測到危險之後會怎樣

## 1. 實際產品怎麼運作（簡報裡要講的）

- 午睡室牆上的攝影機 → 教室裡一台小主機（插著 UGen300）→ **影像只在這台主機上處理，不上雲、不出教室**。
- 偵測到危險時，三個地方會知道：
  1. **教室裡**：主機接的喇叭發出警報聲；平板或螢幕上的**情報版**顯示是哪一床。（響鈴會不會吵醒其他寶寶？訪談時確認，也可能改成老師手機震動或燈號。）
  2. **托育人員的手機**：透過中心內部 Wi-Fi 收到文字通知，例如「2 號床：口鼻看不到 12 秒」。**只傳文字，不傳影像。**
  3. **紀錄**：每次警示、多久後恢復，都自動記下來。托嬰中心事後可以查——這是法規和訴訟上的保障，也是商業賣點。
- **沒人處理**：紅色警示 30 秒內沒有恢復，就加大聲音、再通知主管。

## 2. 情報版長怎樣

```
┌──────────────────────────────┬─────────────────────────┐
│ 午睡室 A｜影像只在本機處理      │ 床位狀態                  │
│                               │ 1 號床  ● 正常            │
│   [1] 綠框     [2] 紅框 12 秒   │ 2 號床  ● 警示 12 秒       │
│                               │ 3 號床  ● 正常            │
│          [3] 綠框             │ ────────────────        │
│                               │ 事件紀錄                  │
│                               │ 14:02:11 2號床 口鼻看不到  │
│                               │ 14:02:31 2號床 恢復（20秒）│
└──────────────────────────────┴─────────────────────────┘
```

每個嬰兒各自的狀態，互不影響：
- **綠：正常**——口鼻看得到。
- **黃：觀察中**——口鼻看不到，還不到 10 秒（輕提示音）。
- **紅：警示**——口鼻看不到滿 10 秒（明確的警報聲＋手機通知）。demo 用 10 秒；實際要幾秒可以調，之後跟托育人員討論。
- **橘：注意**（之後加）——趴睡但口鼻看得到。
- 口鼻要連續看得到約 1 秒才回到綠色，避免偵測器誤把別的東西當成臉、一閃就把計時歸零。

## 4. Stage I 做到哪、Stage II 再做什麼

| | Stage I（10/14 前） | Stage II（入圍後） |
|---|---|---|
| 情報版 | 程式直接畫在輸出影片上 | 做成中心內部網頁，平板、電腦都能開 |
| 警報聲 | 影片後製加入 | 主機真的發出聲音 |
| 手機通知 | 用畫面示意（標明是示意） | 真的推播到手機 |
| 處理紀錄 | 口鼻重新看得到就自動記「恢復」和秒數 | 加上「已處理」按鈕，記錄誰處理、花多久 |
| 運算 | 筆電 | UGen300 |

## 5. 去托嬰中心訪談時要問的

**介面與提醒**
1. 午睡時老師人在哪？手上有沒有手機、平板？（決定通知要送到哪裡）
2. 發現危險時，希望怎麼被提醒：教室裡響鈴、手機震動、手錶、燈號？**響鈴會不會吵醒其他寶寶？**
3. 螢幕放哪裡最方便（午睡室門口、辦公室）？一眼想看到什麼（床位顏色、秒數、畫面）？
4. 一次午睡能接受幾次誤報？誤報多了會怎麼做？

**現況與規定**
5. 午睡室多大、一間幾個寶寶、幾位老師？睡床還是地墊？
6. 現在多久巡一次？要不要填巡視紀錄？我們的自動紀錄能不能幫上忙？
7. 監視器誰在看、錄影存多久？家長怎麼看待教室裡的攝影機？

**攝影機與光線**（最重要：灰階模擬測試顯示，畫面有沒有顏色、臉有多大，誤報可以差三倍；我們手上沒有任何真實午睡室的資料）
8. 睡眠區的監視器裝在哪、多高、朝哪個方向？一台拍幾床？知道型號或解析度嗎？
9. 午睡時燈全關嗎？窗簾拉到多暗？有沒有小夜燈？
10. 午睡時監視器畫面是**彩色還是黑白（夜視）**？法規要求睡眠區畫面「彩色、清晰可辨識」，實際關燈時會不會自動切成黑白？
11. 方便的話，在**沒有孩子的時段**讓我們看一眼（或拍一張）午睡燈光下的空睡眠區監視畫面——一張就看得出顏色、角度、臉大概幾個像素。
12. 孩子午睡時被子通常蓋到哪裡？（身體被蓋住時，臉是唯一的線索）

**購買與顧慮**
13. 這類設備通常誰決定買？大概能接受多少預算？
14. 最擔心什麼：隱私、誤報、操作麻煩、費用？

**注意**
- 先說明來意、徵求同意。不要拍孩子，拍環境也要先問。
- 空睡眠區的監視畫面：確認畫面裡沒有孩子；只當內部參考，想放進簡報要另外問。
- 帶第 2 節的情報版草圖給他們看，問哪裡要改。
- 記下原話；想放進簡報的話，問對方可不可以具名。
