## 重要限制

- **雲端工作階段沒有 `dataset/`（娃娃影片）和 `outputs/`（每幀判定、VLM 時間軸、已輸出的影片）**——都不在 GitHub。
  所以雲端只能**寫程式**，用假資料（自己產生的小 JSON／純色測試影片）測流程；**真正輸出要 Harry 在本機跑**。每個程式都要寫清楚本機怎麼跑。
- 畫面只能用自己拍的娃娃影片。網路圖片、新聞圖、SyRIP 圖、真實嬰兒一律不用。
- 燈號必須是系統真實輸出（來自 `crib_context.py`／`demo_render.timeline_states()` 的狀態）；安裝流程、手機推播是**介面原型**，畫面角落固定標 "UI prototype · doll re-enactment"。
- 燈號定義跟簡報第 10 頁一致：綠＝口鼻看得到；黃＝3 秒倒數中，或偵測器說看得到、VLM 說看不到（只在護理站顯示、不推播）；紅＝連續 3 秒看不到，推播給護理師；藍＝大人在床邊、暫停計時；灰＝空床。
- 英文介面；產品名暫用 **FirstGlance**，做成一個常數方便替換。
- 改完 commit 到 `doll-eval`（不要動 `main`，Harry 確認後再合併）；不要 push 到別的分支。

## 素材 1：開場雙畫面（`demo_render.py --split`）

1920×1080、約 15 秒。左半：家長手機直播畫面（手機外框、「Live · Crib 07」、時間、沒有任何 AI 標記，只播原始娃娃畫面）。
右半：同一段畫面的護理站單床卡片（燈號外框＋狀態）。用 IMG_8432 約 86–100 秒（藍 → 黃 → 紅）。
紅燈出現時右下角跳出「護理師手機推播」小卡（"Crib 07 · nose and mouth hidden 3 s"）並輕微震動效果；左邊家長畫面不變。
最後 2 秒疊字幕："Same crib, same second. The nurse knows first."
做法：在 `demo_render.py` 加 `--split` 模式，重用 `timeline_states()`、`STATES`、字型設定。本機跑：`uv run python demo_render.py --split`，輸出 `outputs/demo/split_open.mp4`。

## 素材 2：可以點的護理站介面原型（`demo_ui/`）

單一靜態網頁（HTML＋原生 JS＋CSS，不用建置工具），開瀏覽器就能用，讓隊員邊點邊錄螢幕。

- **資料**：`demo_ui/export_assets.py`（本機跑）把 `outputs/crib_context/`、`outputs/vlm_spike/timeline_*.csv`、`outputs/video_eval/*_frames.csv`
  經 `demo_render.timeline_states()` 轉成 `demo_ui/data/cribs.json`（每床：影片檔名、開始／結束秒、每 0.2 秒的燈號），並把要用的片段剪好複製到 `demo_ui/media/`。
  床位組合沿用 `demo_render.GRID`（8 床，07 號是主角）。`demo_ui/data/`、`demo_ui/media/` 加進 `.gitignore`（是娃娃影片，但沒必要進 repo）；另附一份假資料 `demo_ui/sample/` 讓雲端能開發。
- **畫面**（依序就是影片的操作示範）：
  1. **安裝**：選一張床 → 在第一幀上拖曳框出床位 → 點一下標床頭 → 按「Capture empty-crib photo」→ 完成（純前端示意，存在 localStorage 即可）。
  2. **護理站牆面**：4×2 床位影片磚，各自燈號外框與狀態標籤；右側事件列表、各色數量（同 `nurse_station.mp4` 的版面）。所有影片同步播放，燈號依 JSON 隨時間更新。
  3. **單床詳細**：點一床 → 大畫面＋右側「What the box sees」四個訊號＋本段時間軸（同 `demo_render.py` 單床版面）。
  4. **紅燈處理**：紅燈時跳出提示，按「Acknowledge · I'm at the crib」→ 事件列表記一筆（顯示從警示到確認的秒數）。
  5. **手機推播**：畫面右下可開關一個手機框，紅燈時顯示推播通知（只有文字，沒有影像——跟簡報「text only, never images」一致）。
- 不要接後端、不要任何外部請求；字型用系統字。測試：用假資料在瀏覽器點過每個流程。

## 素材 3：筆電即時判讀（`live_view.py`）

本機跑的小程式：讀一支娃娃影片，**即時**（按影片原速）跑 v3＋床位判讀（每秒 5 幀）＋床位情境狀態機，用 OpenCV 視窗顯示：
左邊鏡頭畫面＋臉框＋燈號外框，右上角顯示每幀處理毫秒數、目前 FPS、「Running on: laptop CPU (Intel i7-11800H)」。
目的是讓評審看到「真的在跑」，不是事先算好的。重用 `eval_video.detect()`、`crib_context.CribState`／`features` 的特徵算法（要改成逐幀即時算，不能先讀整支影片）。
VLM 不即時跑（筆電 GPU 另一個環境），畫面上不顯示 VLM。本機跑：`uv run python live_view.py IMG_8432 --start 80`，隊員用 Windows 的 Win+Alt+R 或 OBS 錄螢幕。
